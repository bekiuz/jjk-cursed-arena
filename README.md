# JJK Cursed Arena

An unofficial, fan-made 2D/2.5D browser fighting-game prototype inspired by the world of Jujutsu Kaisen. The current build uses original canvas-drawn visuals and does not bundle third-party character models or textures.

## Play

Open the GitHub Pages site after Pages deployment is enabled, or run a local static server:

```powershell
py -m http.server 8080
```

Then visit http://localhost:8080.

## Controls

- A / D — move
- W — jump
- S — guard
- Shift — dash
- J — quick strike
- K — heavy strike
- L — cursed technique
- R — restart

Touch controls are included for mobile.

## Current prototype

- Responsive canvas arena with anime-inspired lighting and original drawn fighters
- Yuji-inspired starter fighter and cursed spirit opponent
- Lightweight opponent AI, health and cursed-energy meters, round timer, hit feedback and special-effect bursts
- Four selectable fighter presets (Yuji, Gojo, Megumi and Nobara)
