# Character models

Place the Yuji Itadori GLB file here with this exact name:

`test-anime-fighter.glb`

The 3D game loads it from:

`assets/characters/test-anime-fighter.glb`

The model is optional. When no GLB is present, the game uses its built-in smooth anime-style 3D model. Only add models that you have permission to use and redistribute.
